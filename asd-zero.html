1

Что такое алгоритм и как читать псевдокод

Алгоритм — чёткая последовательность шагов, которая из входных данных за конечное число шагов даёт результат. Свойства: конечность, однозначность шагов, есть вход и выход.

На ASD алгоритмы пишут псевдокодом — похоже на программу, но без строгого синтаксиса:

Max(A, n):               // A — массив из n чисел
    m = A[1]
    для i = 2 до n:
        если A[i] > m:
            m = A[i]
    вернуть m

Главный навык — трассировка: берёшь маленькие данные и выполняешь алгоритм шаг за шагом, записывая значения переменных в таблицу. Так отвечают на вопросы «что выведет алгоритм», «в каком порядке посетятся вершины», «что будет после 2-го прохода».

Трассировка Max для A = [3, 8, 2, 9, 4]: m=3 → i=2: 8>3, m=8 → i=3: 2>8? нет → i=4: 9>8, m=9 → i=5: 4>9? нет. Ответ 9. Сравнений n − 1 = 4.

Сложность и нотация O

Сложность — как растёт время (число операций) при росте размера входа n. Константы и мелкие слагаемые отбрасываем: 3n² + 5n + 7 → O(n²).

Как оценить по коду: один цикл до n → O(n); цикл в цикле → O(n²); n делится пополам на каждом шаге → O(log n); рекурсия, делящая задачу пополам и просматривающая все элементы на каждом уровне → O(n log n).

Худший (worst), средний и лучший случаи могут отличаться: быстрая сортировка в худшем — O(n²), в среднем — O(n log n). Подробнее и сравнение — на странице лекции 26.10.

3

Структуры данных: массив, список, стек, очередь

  • Массив — элементы подряд, доступ по индексу за O(1), вставка в середину O(n).
  • Связный список — элементы хранят ссылку на следующий; вставка по ссылке O(1), поиск O(n).
  • Стек (LIFO) — последним пришёл, первым вышел: push (положить), pop (снять с вершины). Используется в DFS и рекурсии.
  • Очередь (FIFO) — первым пришёл, первым вышел: enqueue в конец, dequeue из начала. Используется в BFS.
Пример. push 1, push 2, push 3, pop → 3, pop → 2; в стеке остаётся 1. Та же последовательность в очереди (dequeue дважды) даст 1, 2; останется 3.
4

Куча и очередь с приоритетом

Min-heap (куча-минимум) — двоичное дерево, где родитель ≤ детей; минимум всегда в корне. Хранится в массиве: для элемента с индексом i (с 0) родитель (i−1)//2, дети 2i+1 и 2i+2.

  • Вставка: добавить в конец, затем «всплывать»: пока родитель больше — менять местами.
  • Извлечение минимума: взять корень, на его место поставить последний элемент, затем «топить»: менять с меньшим из детей, пока не восстановится порядок.
  • Обе операции — O(log n). Очередь с приоритетом (в алгоритме Прима) делают на куче.
Вставка. Куча [2, 5, 3, 9, 6], вставляем 1: [2, 5, 3, 9, 6, 1] → родитель 3 больше → меняем: [2, 5, 1, 9, 6, 3] → родитель 2 больше → меняем: [1, 5, 2, 9, 6, 3].
Извлечение min из неё: забираем 1, ставим 3 в корень: [3, 5, 2, 9, 6] → дети 5 и 2, меньший 2 → меняем: [2, 5, 3, 9, 6].
5

Поиск

  • Линейный: проверяем элементы по порядку, O(n), массив может быть любым.
  • Бинарный: только в отсортированном массиве. Сравниваем с серединой и отбрасываем половину: O(log n).
BinarySearch(A, x):
    lo = 1; hi = n
    пока lo <= hi:
        mid = (lo + hi) / 2   // целая часть
        если A[mid] == x: вернуть mid
        если A[mid] < x: lo = mid + 1
        иначе: hi = mid - 1
    вернуть «нет»
Трассировка. A = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91] (индексы с 0), ищем 23. lo=0, hi=9, mid=4 (16 < 23) → lo=5. mid=7 (56 > 23) → hi=6. mid=5 (23) — найдено, индекс 5. Три сравнения вместо шести при линейном поиске.
6

Простые сортировки

Три «квадратичные» сортировки O(n²), которые легко трассировать.

  • Пузырьком: проходим массив, меняем местами соседние, если они в неправильном порядке; наибольший «всплывает» в конец.
  • Вставками: левая часть всегда отсортирована; берём следующий элемент и вставляем на место.
  • Выбором: находим минимум в неотсортированной части и ставим на очередное место.
Пузырёк на [5, 2, 4, 1]:
1-й проход: [2, 5, 4, 1] → [2, 4, 5, 1] → [2, 4, 1, 5].
2-й проход: [2, 4, 1, 5] → [2, 1, 4, 5].
3-й проход: [1, 2, 4, 5] — готово.
Вставками на том же массиве: [5] → [2, 5] → [2, 4, 5] → [1, 2, 4, 5].

Быстрые сортировки — merge sort и quick sort (O(n log n)) — разобраны на странице лекции 26.10: слияние, выбор опорного элемента, стабильность.

7

Рекурсия

Функция вызывает сама себя на меньшей задаче. Нужны два элемента: базовый случай (когда не вызываем себя) и шаг, приближающий к базе. Вызовы хранятся в стеке.

Fact(n):
    если n <= 1: вернуть 1
    вернуть n * Fact(n - 1)

Gcd(a, b):                 // алгоритм Евклида
    если b == 0: вернуть a
    вернуть Gcd(b, a mod b)
Fact(4) = 4·Fact(3) = 4·3·Fact(2) = 4·3·2·Fact(1) = 4·3·2·1 = 24.
Gcd(48, 18): 48 mod 18 = 12 → Gcd(18, 12): 18 mod 12 = 6 → Gcd(12, 6): 12 mod 6 = 0 → Gcd(6, 0) = 6.
Фибоначчи F(n) = F(n−1) + F(n−2) наивно считается повторно: для F(5) выполняется 15 вызовов, время растёт как 2ⁿ.
Ханойские башни: для n дисков нужно 2ⁿ − 1 ходов (n = 3 → 7).

Подробнее: рекурсия и графы (26.10).

Типы заданий и как их решать

ЗаданиеЧто делать
«Что выведет алгоритм / какой результат?»Трассировка с таблицей значений переменных.
«Оцените сложность»Посчитай вложенность циклов и деление задачи; ответ в O(·), худший случай.
«Выполни сортировку по шагам»Выпиши массив после каждого прохода (или слияния).
«Бинарный поиск числа x»Таблица lo, hi, mid, сравнение; считай шаги.
«Вставь/удали элемент из кучи»Показывай массив после каждого обмена.
«Обход графа BFS/DFS»Выпиши очередь/стек и порядок посещения; при выборе соседей — по алфавиту/номерам, если не сказано иное.
«Построй MST (Прим/Краскал)»Таблица рёбер по весам; для каждого — берём или цикл; итоговая сумма; всего n − 1 ребро.
«Напиши псевдокод»Опиши цикл, условие и результат; проверь на маленьком примере.
Совет. При любой трассировке пиши промежуточные шаги — частичные баллы дают за ход, а ошибка в одном шаге не обнуляет остальное.
