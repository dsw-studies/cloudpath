Matematyka · функция и её график

Квадратичная функция и парабола

Конспект по записи занятия: общий вид, корни, вершина, три формы записи и графики для разных знаков дискриминанта.

1. Общий вид и направление ветвей

f(x) = ax² + bx + c,   a ≠ 0

График — парабола. Если a > 0, ветви направлены вверх и вершина является минимумом. Если a < 0, ветви направлены вниз и вершина является максимумом.

2. Дискриминант и корни

Δ = b² − 4ac   ·   x = (−b ± √Δ)/(2a)
УсловиеЧто происходит
Δ > 0Два различных действительных корня
Δ = 0Один двойной корень x₀ = −b/(2a)
Δ < 0Действительных корней нет

3. Вершина и три формы записи

Общий вид

ax² + bx + c

Канонический вид

a(x − p)² + q

p = −b/(2a),   q = −Δ/(4a)

Вид по корням

a(x − x₁)(x − x₂)

При двойном корне: a(x − x₀)².

Координаты вершины W(p,q). Если корни существуют, p = (x₁ + x₂)/2 — середина между ними.

4. Как меняются графики

На каждой паре знак a задаёт направление ветвей, а дискриминант определяет число пересечений с осью x.

5. Разобранные примеры из занятия

Пример 1. Корни 7 и −1, минимум −4

p = (7 + (−1))/2 = 3f(x) = a(x − 7)(x + 1)−4 = f(3) = a(−4)(4) = −16a ⇒ a = 1/4
f(x) = ¼(x − 7)(x + 1)

Пример 2. Вершина (1,2), один корень 0

f(x) = a(x − 1)² + 20 = f(0) = a + 2 ⇒ a = −2
f(x) = −2(x − 1)² + 2 = −2x(x − 2)

Проверка: второй корень равен 2, ветви направлены вниз.

Пример 3. Найти c в f(x)=x²+5x+c

а) График проходит через (−2,1): 1 = 4 − 10 + c, поэтому c = 7.

б) Ровно один корень: Δ = 25 − 4c = 0, значит c = 25/4.

в) Минимум равен −5/4. Здесь q = c − 25/4, откуда c = 5.

Пример 4. Старший коэффициент 1, корни −2 и 5

f(x) = (x + 2)(x − 5)
f(x) = x² − 3x − 10,   b = −3, c = −10
