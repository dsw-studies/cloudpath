Действительные числа и степени

Конспект отделяет математические темы от курса «Алгоритмы и структуры данных». Основа — присланные расшифровки занятий: числовые множества, свойства степеней и вычислительные примеры.

← Ко всем конспектам

Границы материала. В расшифровках также перечислен план курса: дроби, погрешности, проценты, интервалы, уравнения и неравенства с модулем, функции и системы. Здесь подробно разобраны только темы, которые есть в доступном тексте. Расшифровка файла от 17:36 длиннее соответствующего видео, поэтому её полноту нужно проверить.

1. Числовые множества

Числа объединяются во вложенные множества:

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ
ℕ — натуральные

В этой лекции сюда включён ноль: 0, 1, 2, 3, …

ℤ — целые

Натуральные числа, ноль и противоположные им числа: …, −2, −1, 0, 1, 2, …

ℚ — рациональные

Числа вида m/n, где m,n — целые и n ≠ 0. Например, −3/4 и 5.

ℝ \ ℚ — иррациональные

Действительные числа, которые нельзя представить отношением двух целых чисел, например √2 и π.

Простые числа. Натуральное число простое, если имеет ровно два положительных делителя: 1 и само себя. Число 1 не является ни простым, ни составным; первое простое число — 2.

2. Степени: правила вычислений

Для ненулевого основания и целых показателей действуют правила:

ПравилоФормулаПример
Умножение одинаковых основанийam · an = am+n23 · 24 = 27
Деление одинаковых основанийam / an = am−n56 / 53 = 53
Степень степени(am)n = amn(23)2 = 26
Нулевой показательa0 = 1, если a ≠ 070 = 1
Отрицательный показательa−n = 1/an2−3 = 1/8
Одинаковый показательan · bn = (ab)n23 · 53 = 103
Дробный показательan/m = m√(an)81/3 = 2

Для корней в действительных числах учитывай область определения: например, корень чётной степени от отрицательного числа не является действительным.

3. Разбор примеров

Пример A. Представить одним степенным выражением
0,1253 · 32−2

Преобразуем числа к основанию 2: 0,125 = 1/8 = 2−3, а 32 = 25.

(2−3)3 · (25)−2 = 2−9 · 2−10 = 2−19
Пример B. Свести к общей основе
(0,4)7 · (2,5)−4 / (2/5)5

0,4 = 2/5, а 2,5 = 5/2 = (2/5)−1. Поэтому (2,5)−4 = (2/5)4.

(2/5)7 · (2/5)4 / (2/5)5 = (2/5)7+4−5 = (2/5)6
Пример C. Сократить большие степени до вычисления
(56 + 20·54) / (2·56 − 100·53)

В числителе и знаменателе выносим 53:

[53(53 + 20·5)] / [53(2·53 − 100)] = 225/150 = 3/2

Liczby rzeczywiste i potęgi

Ta notatka jest oddzielona od przedmiotu „Algorytmy i struktury danych”. Opiera się na przesłanych transkrypcjach: zbiorach liczbowych, prawach działań na potęgach i przykładach obliczeniowych.

← Wszystkie notatki

Zakres materiału. Transkrypcje wymieniają też plan kursu: ułamki, błędy przybliżeń, procenty, przedziały, równania i nierówności z wartością bezwzględną, funkcje oraz układy. Poniżej szczegółowo opracowano tylko zagadnienia obecne w dostępnym tekście. Transkrypcja pliku z 17:36 jest dłuższa od odpowiadającego jej filmu, więc jej kompletność wymaga weryfikacji.

1. Zbiory liczbowe

Zbiory liczb są zagnieżdżone:

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ
ℕ — liczby naturalne

W tym wykładzie zero jest zaliczone do ℕ: 0, 1, 2, 3, …

ℤ — liczby całkowite

Liczby naturalne, zero i liczby przeciwne: …, −2, −1, 0, 1, 2, …

ℚ — liczby wymierne

Liczby postaci m/n, gdzie m,n są całkowite i n ≠ 0. Przykłady: −3/4 i 5.

ℝ \ ℚ — liczby niewymierne

Liczby rzeczywiste, których nie można zapisać jako ilorazu dwóch liczb całkowitych, np. √2 i π.

Liczby pierwsze. Liczba naturalna jest pierwsza, jeśli ma dokładnie dwa dodatnie dzielniki: 1 i samą siebie. Liczba 1 nie jest ani pierwsza, ani złożona; najmniejszą liczbą pierwszą jest 2.

2. Potęgi: reguły obliczeń

Dla niezerowej podstawy oraz całkowitych wykładników obowiązują następujące reguły:

RegułaWzórPrzykład
Mnożenie potęg o tej samej podstawieam · an = am+n23 · 24 = 27
Dzielenie potęg o tej samej podstawieam / an = am−n56 / 53 = 53
Potęga potęgi(am)n = amn(23)2 = 26
Wykładnik zerowya0 = 1, gdy a ≠ 070 = 1
Wykładnik ujemnya−n = 1/an2−3 = 1/8
Ten sam wykładnikan · bn = (ab)n23 · 53 = 103
Wykładnik ułamkowyan/m = m√(an)81/3 = 2

W zbiorze liczb rzeczywistych trzeba uwzględnić dziedzinę pierwiastka: pierwiastek parzystego stopnia z liczby ujemnej nie jest liczbą rzeczywistą.

3. Przykłady z rozwiązaniem

Przykład A. Zapisz jako jedną potęgę
0,1253 · 32−2

Zapisujemy liczby przy podstawie 2: 0,125 = 1/8 = 2−3, a 32 = 25.

(2−3)3 · (25)−2 = 2−9 · 2−10 = 2−19
Przykład B. Sprowadź do wspólnej podstawy
(0,4)7 · (2,5)−4 / (2/5)5

0,4 = 2/5, a 2,5 = 5/2 = (2/5)−1. Zatem (2,5)−4 = (2/5)4.

(2/5)7 · (2/5)4 / (2/5)5 = (2/5)7+4−5 = (2/5)6
Przykład C. Skróć potęgi przed obliczeniem
(56 + 20·54) / (2·56 − 100·53)

Wyłączamy 53 przed nawias w liczniku i mianowniku:

[53(53 + 20·5)] / [53(2·53 − 100)] = 225/150 = 3/2
