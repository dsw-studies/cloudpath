Zadanie 1 (5 pkt): 2x − 4y + 6 = 0, E(1, 1)

Нормальный вектор прямой n=[2, −4], направляющий v=[4, 2] ∥ [2, 1]; наклон k = 2/4 = 1/2 (y = ½x + 3/2).

a) перпендикулярная через E: нормальный вектор — [4, 2] ∥ [2, 1]. 2(x−1) + 1(y−1) = 0 ⇒ 2x + y − 3 = 0 (y = −2x + 3, наклон −2 = −1/k ✓).

b) параллельная через E: тот же нормальный вектор [2, −4]. 2(x−1) − 4(y−1) = 0 ⇒ 2x − 4y + 2 = 0 ⇒ x − 2y + 1 = 0 (y = ½x + ½ ✓, E: 1−2+1=0).

Zadanie 2 (5 pkt): A (2×3), B (3×3), C (3×2)

A = \(\begin{bmatrix}1&3&0\\0&-1&4\end{bmatrix}\) B = \(\begin{bmatrix}1&4&7\\2&-1&0\\5&-2&8\end{bmatrix}\) C = \(\begin{bmatrix}1&-2\\0&7\\-1&4\end{bmatrix}\)

a) A − 3Cᵀ. Cᵀ (2×3) = \(\begin{bmatrix}1&0&-1\\-2&7&4\end{bmatrix}\) 3Cᵀ = \(\begin{bmatrix}3&0&-3\\-6&21&12\end{bmatrix}\) A − 3Cᵀ = \(\begin{bmatrix}-2&3&3\\6&-22&-8\end{bmatrix}\) (размеры совпадают: 2×3).

b) AB: размеры \(2\times3\) и \(3\times3\): число столбцов A равно числу строк B, поэтому произведение определено, результат \(2\times3\). Каждый элемент — строка A на столбец B:

\[ AB=\begin{bmatrix}1\cdot1+3\cdot2+0\cdot5 & 1\cdot4+3\cdot(-1)+0\cdot(-2) & 1\cdot7+3\cdot0+0\cdot8\\ 0\cdot1+(-1)\cdot2+4\cdot5 & 0\cdot4+(-1)(-1)+4\cdot(-2) & 0\cdot7+(-1)\cdot0+4\cdot8\end{bmatrix}=\begin{bmatrix}7&1&7\\18&-7&32\end{bmatrix} \]

c) CB: C — 3×2, B — 3×3. Столбцов у C (2) ≠ строк у B (3), поэтому произведение CB не определено.

Zadanie 3 (5 pkt)

a) Раскладываем по 3-й строке: в ней единственный ненулевой элемент \(-1\) (столбец 2), знак \((-1)^{3+2}=-1\).

\[ X=\begin{bmatrix}2&0&3&-5\\1&0&4&-1\\0&-1&0&0\\2&0&0&1\end{bmatrix},\qquad \det X=(-1)\cdot(-1)^{3+2}\cdot M=M,\quad M=\begin{vmatrix}2&3&-5\\1&4&-1\\2&0&1\end{vmatrix} \]

По правилу Саррюса:

\[ \begin{aligned}M&=(2\cdot4\cdot1+3\cdot(-1)\cdot2+(-5)\cdot1\cdot0)\\ &\quad-((-5)\cdot4\cdot2+2\cdot(-1)\cdot0+3\cdot1\cdot1)\\ &=2-(-37)=39\end{aligned} \]

Проверка разложением по 1-му столбцу: \(2(4-0)-1\cdot(3\cdot1-(-5)\cdot0)+2\cdot(3\cdot(-1)-(-5)\cdot4)=8-3+2\cdot17=39\). \(\det X=39\).

b) det(D²⁰²⁷) = (det D)²⁰²⁷ = (−1)²⁰²⁷ = −1 (нечётная степень). det(3D) = 3⁴·det D = 81·(−1) = −81 (порядок матрицы 4: умножение на k умножает каждую из 4 строк на k).

Ключевые свойства: det(AB)=det A·det B; det(Aᵀ)=det A; det(kA)=kⁿ·det A; при разложении по строке знак (−1)^(i+j).
