map и filter

map(функция, коллекция) применяет функцию к каждому элементу, filter(условие, коллекция) оставляет только подходящие. Оба возвращают «ленивый» итератор: чтобы увидеть результат, оборачивают в list(...) (иначе увидишь только адрес объекта). Обычно в них передают lambda (короткая безымянная функция).

nums = [1, 2, 3, 4]
sq = list(map(lambda x: x * x, nums))
print(sq)
names = ["Ola", "Marek", "Ewa", "Jan", "Karolina"]
three = list(filter(lambda s: len(s) == 3, names))
print(three)
books = [("A", 300), ("B", 120), ("C", 210)]
print(sorted(books, key=lambda b: b[1]))
# вывод:
[1, 4, 9, 16]
['Ola', 'Ewa', 'Jan']
[('B', 120), ('C', 210), ('A', 300)]

== и is. == сравнивает значения; is — один ли это объект в памяти (на лекции говорилось «три равно», как в JavaScript; в Python для этого is). Два одинаковых по содержимому списка равны по ==, но это разные объекты.

a = [1, 2]
b = [1, 2]
print(a == b, a is b)
# вывод:
True False

Регулярные выражения (модуль re)

Модуль re нужен для поиска по шаблону в тексте (парсинг сайтов, валидация, grep в Linux на следующем семестре, автоматизация тестов). Шаблон пишут как сырую строку r"..." (приставка b"..." — это байты, например в RSA).

ФункцияЧто делает
re.match(p, s)совпадение с началом строки
re.search(p, s)первое совпадение где угодно
re.findall(p, s)список всех совпадений
re.finditer(p, s)итератор совпадений (можно посчитать)
re.sub(p, new, s)найти и заменить (как Ctrl+H)
re.split(p, s)разбить строку по шаблону
re.compile(p)заранее скомпилировать шаблон, если он используется много раз (быстрее)
import re
text = "tel 123-456, tel 789-012"
print(re.findall(r"\d{3}-\d{3}", text))
print(re.sub(r"\d", "#", "a1b22"))
print(re.split(r",\s*", "a, b,c"))
mail = re.compile(r"^[\w.]+@[\w.]+\.[a-z]{2,}$")
print(bool(mail.match("jan@dsw.edu.pl")), bool(mail.match("jan@@x")))
# вывод:
['123-456', '789-012']
a#b##
['a', 'b', 'c']
True False

Документация функции (docstring)

Тройные кавычки сразу под def — это docstring. В PyCharm и VS Code он показывается при наведении на функцию в любом месте проекта (в Colab, где всё в одном файле, это не заметно).

def area(a, b):
    """Площадь прямоугольника: a * b."""
    return a * b
print(area.__doc__)
print(area(3, 4))
# вывод:
Площадь прямоугольника: a * b.
12

Стек и очередь

Стек (stack) — LIFO: последний пришёл — первый ушёл. Операции: push (положить), pop (снять верхний), empty/full. Нужен для вызовов функций, отмены, обхода графа в глубину. В Python стек — обычный список: append и pop() (снимает последний элемент).

Очередь (queue) — FIFO: первый пришёл — первый ушёл (enqueue — добавить в конец, dequeue — взять с начала); буфер между программами. Лучше брать collections.deque, у неё popleft() быстрый, а у списка pop(0) медленный.

stack = []
stack.append(1); stack.append(2); stack.append(3)
print(stack.pop(), stack)
from collections import deque
q = deque()
q.append("a"); q.append("b"); q.append("c")
print(q.popleft(), list(q))
# вывод:
3 [1, 2]
a ['b', 'c']
5

array, дерево, связный список, куча, граф

  • array (модуль array) — массив с одним заданным типом ("i" — целые), в отличие от списка, который принимает что угодно; неверный тип даст TypeError. Для больших числовых вычислений используют NumPy (основа машинного обучения).
  • Бинарное дерево поиска (BST): слева меньшие, справа большие значения, поэтому искать быстро (путь короткий). Минус: при вставке/удалении дерево перестраивается, значит оно хорошо там, где данные меняются редко. Деревья используются в индексах БД, файловых системах и в хэш-деревьях (Merkle) в блокчейне и IPFS.
  • Связный список: узлы, каждый ссылается на следующий.
  • Куча (heap) — разновидность дерева (см. ASD 13.11); в Python модуль heapq.
  • Граф: вершины и рёбра; хранят словарём «вершина → соседи». Поиск кратчайшего пути, карты, рекомендации друзей. Для больших графов используют графовые БД (Neo4j, ArangoDB).
from array import array
a = array("i", [1, 2, 3])
a.append(4)
print(a, a[0])
try:
    a.append("x")
except TypeError as e:
    print("TypeError")
graph = {"A": ["B", "C"], "B": ["A"], "C": ["A"]}
print(graph["A"])
# вывод:
array('i', [1, 2, 3, 4]) 1
TypeError
['B', 'C']

Специальные словари: collections

  • defaultdict: если ключа нет, значение создаётся автоматически (нет ошибки KeyError при подсчётах и группировке).
  • Counter: подсчёт, сколько раз встречается каждый элемент.
  • ChainMap: несколько словарей как один (поиск по очереди).
  • deque, OrderedDict, UserDict/UserList — прочее.
  • Хэш-таблица (dict): ключ превращается в хэш, по нему значение находится мгновенно.
from collections import defaultdict, Counter, ChainMap
g = defaultdict(list)
for w in ["ala", "ola", "ewa", "adam"]:
    g[w[0]].append(w)
print(dict(g))
users = [{"age": 17}, {"age": 21}, {"age": 30}]
print(Counter(u["age"] >= 18 for u in users))
print(Counter("banana"))
cm = ChainMap({"a": 1}, {"a": 9, "b": 2})
print(cm["a"], cm["b"])
# вывод:
{'a': ['ala', 'adam'], 'o': ['ola'], 'e': ['ewa']}
Counter({True: 2, False: 1})
Counter({'a': 3, 'n': 2, 'b': 1})
1 2

На лекции приводился пример с JSON пользователей (логин, возраст…): подсчёт «сколько старше 18» удобно делать Counter. Тяжёлые вычисления можно переложить на сервер БД: у неё свой процессор и память; хуже всего считать на стороне клиента (frontend).

Копирование: переменная — это ссылка

Переменная в Python — ссылка (указатель) на объект в памяти, а не сама ячейка. Присваивание b = a не копирует список, обе переменные указывают на один и тот же объект. Виды копии:

  • b = a — тот же объект;
  • a.copy() / copy.copy(a) — поверхностная копия: новый внешний список, но вложенные объекты общие;
  • copy.deepcopy(a) — глубокая, полностью независимый клон.
import copy
a = [1, 2, [10, 20]]
b = a
c = a.copy()
d = copy.deepcopy(a)
a.append(3)
a[2].append(30)
print("a", a)
print("b", b)
print("c", c)
print("d", d)
# вывод:
a [1, 2, [10, 20, 30], 3]
b [1, 2, [10, 20, 30], 3]
c [1, 2, [10, 20, 30]]
d [1, 2, [10, 20]]

Вывод: b изменился целиком, c получил общий вложенный список ([10, 20, 30]), а d не изменился совсем. Если сомневаешься — делай deepcopy.

Сортировки (обзор) и отладка

Обзор в конце лекции (подробно — на ASD и структурах данных):

  • Пузырьком (bubble): сравниваем элемент со следующим и меняем местами, если порядок неверный; проходим до конца.
  • Быстрая (quick sort): «разделяй и властвуй»; выбираем опорный элемент (pivot), меньшие уходят влево, большие вправо, затем так же сортируем части. Части можно отдать разным потокам/процессам процессора и в конце проверить стыки: так быстрее на больших данных.
  • Корзинная (bucket): элементы раскладываются по «корзинам» близких значений, внутри корзин сортируют, потом склеивают. Похожа на сортировку подсчётом (counting sort), которую уже проходили.
  • Слиянием (merge) и кучей (heap sort) тоже упомянуты. Лектор не советует писать сортировки сам вместо встроенных, кроме как для учёбы.

Отладка (debugger). Не обязательно расставлять print и if: в PyCharm/VS Code ставишь точку останова (красная точка у номера строки), запускаешь в режиме отладки, программа останавливается и показывает значения переменных, дальше идёшь по шагам. Особенно полезно с вложенными циклами и рекурсией (видно, как растёт стек вызовов). Принцип одинаков во всех языках.

Проверь себя

Что вернёт map(...) без list()?
Итератор (объект с адресом), а не список; значения видны после list(...).
Чем отличаются стек и очередь?
Стек — LIFO (последний вошёл, первый вышел), очередь — FIFO.
Чем deepcopy отличается от copy?
copy копирует только внешний уровень, вложенные объекты остаются общими; deepcopy клонирует всё.
Чем == отличается от is?
== сравнивает значения, is — тождественность объектов.
Когда использовать defaultdict?
Когда ключа может не быть и нужно автоматически создать начальное значение (список, число).
Чем плох BST при частых изменениях?
Вставка и удаление требуют перестроения дерева, что дорого на больших объёмах.
Что делает re.sub?
Находит фрагменты по шаблону и заменяет их на указанную строку.
