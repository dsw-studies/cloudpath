Пробный коллоквиум в формате Janusz Grabski (30 минут, 15 баллов) и бесконечный генератор новых вариантов.

ГЕНЕРАТОР

Сгенерировать свой коллоквиум

Формат как в образце: Задание 1 — 5 утверждений P/F (+1 / −1 / 0), Задание 2 — тавтология? (таблица истинности), Задание 3 — три промежутка A, B, C на оси и четыре операции (∪, ∩, ∖, ′). Есть таймер на 30 минут, проверка задания 1 и полное решение заданий 2 и 3.

Zadanie 1 (5 pkt): P/F — верно +1, неверно −1, нет ответа 0

  1. „Wrocław był stolicą Polski” jest zdaniem w sensie logiki matematycznej. → P. Высказывание — это утверждение, у которого есть значение истинности. Здесь оно ложное (или истинное, в зависимости от эпохи), но значение у него есть, поэтому это высказывание.
  2. Wykresem funkcji zdaniowej φ(x, y): x > 0 ∧ y < 0 jest cały układ OXY. → F. Условие задаёт только IV четверть (x > 0 и y < 0, без осей).
  3. Zaprzeczeniem ∀x ∈ ℝ: x³ > 1 jest ∃x ∈ ℝ: x³ < 1. → F. Правильное отрицание: ∃x ∈ ℝ: x³ ≤ 1. Потерян случай равенства (x = 1).
  4. Iloczyn kartezjański dwóch zbiorów może być zbiorem jednoelementowym. → P. Например, {a} × {b} = {(a, b)}.
  5. Dla Fₙ = (−n, 1 + 1/n), n ∈ ℕ₊: ⋃ₙ Fₙ = (−∞, 2). → P. Левые концы −n уходят в −∞. Правый конец 1 + 1/n наибольший при n = 1 и равен 2, при этом F₁ = (−1, 2) открыт справа, поэтому 2 в объединение не входит.

Ответ: P, F, F, P, P.

Zadanie 3 (5 pkt): A = [√2, +∞), B = (−2, 4), C = [−2, 5]

Порядок точек на оси: −2 < √2 ≈ 1,41 < 4 < 5. Отмечаем: A — луч от √2 вправо (√2 включена), B — отрезок от −2 до 4 без концов, C — отрезок от −2 до 5 с концами.

  • A ∪ B = (−2, +∞) — слева начинается B (−2 не входит ни в A, ни в B), справа A уходит в бесконечность.
  • A ∩ C = [√2, 5].
  • C ∖ B = {−2} ∪ [4, 5] — из C убираем (−2, 4); точки −2 и 4 в B не входят, поэтому остаются.
  • A′ = (−∞, √2) — дополнение до ℝ.

Оценка: по баллам за задание ориентируйся на полноту: рисунок оси, верный результат каждой из четырёх операций, обработка концов.
