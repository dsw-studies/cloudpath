1. Минор и алгебраическое дополнение / Minor i dopełnienie algebraiczne

RU. Для элемента aij квадратной матрицы вычеркни строку i и столбец j. Определитель оставшейся матрицы называется минором Mij. Алгебраическое дополнение:

Dij = (−1)i+j · Mij

PL. Aby wyznaczyć minor Mij, skreślamy i-ty wiersz i j-tą kolumnę, a następnie obliczamy wyznacznik pozostałej macierzy. Dopełnienie algebraiczne:

Dij = (−1)i+j · Mij

Знак / Znak: если i+j чётное / parzyste, знак «+»; если нечётное / nieparzyste, знак «−».

+  −  +  −
−  +  −  +
+  −  +  −
−  +  −  +

Пример / Przykład

A = | 1  0   2 |
    | 5  6  −1 |
    | 4  0   3 |

RU. Найдём D21: удаляем вторую строку и первый столбец. Остаётся матрица [[0, 2], [0, 3]]. Её определитель равен 0·3 − 2·0 = 0. Следовательно, D21 = (−1)3·0 = 0.

PL. Wyznaczamy D21: skreślamy drugi wiersz i pierwszą kolumnę. Pozostaje [[0, 2], [0, 3]], której wyznacznik wynosi 0. Zatem D21 = (−1)3·0 = 0.

2. Разложение Лапласа / Rozwinięcie Laplace’a

По строке i / Względem i-tego wiersza:

det(A) = Σk=1…n aik · Dik

По столбцу j / Względem j-tej kolumny:

det(A) = Σk=1…n akj · Dkj

RU. Выбираем любую одну строку или любой один столбец. Каждый элемент умножаем на его алгебраическое дополнение, результаты складываем. Ответ одинаков при любом выборе, если вычисления верны. Для матрицы 3×3 также можно применить правило Саррюса, но для 4×4 оно напрямую не подходит.

PL. Wybieramy dowolny wiersz albo dowolną kolumnę. Mnożymy kolejne elementy przez ich dopełnienia algebraiczne i sumujemy wyniki. Otrzymany wyznacznik nie zależy od wybranego wiersza ani kolumny. Reguła Sarrusa dotyczy macierzy 3×3, nie 4×4.

3. Пример 3×3: результат 17 / Przykład 3×3: wynik 17

C = |  1   4   6 |
    | −1   3   0 |
    |  2  −3   5 |

Разложение по второй строке / Rozwinięcie względem drugiego wiersza:

D₂₁ = (−1)³ · | 4   6 | = −(20 + 18) = −38
                |−3   5 |

D₂₂ = (−1)⁴ · | 1   6 | = 5 − 12 = −7
                | 2   5 |

D₂₃ = (−1)⁵ · | 1   4 | = −(−3 − 8) = 11
                | 2  −3 |

det(C) = (−1)·(−38) + 3·(−7) + 0·11
       = 38 − 21 = 17

Проверка по первому столбцу / Sprawdzenie względem pierwszej kolumny:

D₁₁ = | 3   0 | = 15
      |−3   5 |

D₂₁ = −38

D₃₁ = | 4   6 | = −18
      | 3   0 |

det(C) = 1·15 + (−1)·(−38) + 2·(−18)
       = 15 + 38 − 36 = 17

RU. Оба разложения дают 17. Это полезная проверка правильности знаков и миноров.

PL. Oba rozwinięcia dają 17. To dobry sposób sprawdzenia znaków i minorów.

4. Пример 4×4: результат 90 / Przykład 4×4: wynik 90

В расшифровке при перечислении элементов встречаются оговорки; ниже приведена матрица, которую преподаватель использует в итоговой проверке.

E = | 1   2   3   4 |
    | 0  −1   0   2 |
    | 0   0   3   0 |
    | 5   4   1   2 |

RU. Выбираем третью строку (0, 0, 3, 0). Три слагаемых равны нулю, поэтому остаётся только элемент a33 = 3. Знак (−1)3+3 положительный.

PL. Wybieramy trzeci wiersz (0, 0, 3, 0), ponieważ zawiera trzy zera. Pozostaje tylko składnik z a33 = 3, ze znakiem dodatnim.

det(E) = 3 · (−1)⁶ · | 1   2   4 |
                        | 0  −1   2 |
                        | 5   4   2 |

       = 3 · det(B)

Для B используем правило Саррюса / Dla B stosujemy regułę Sarrusa:

det(B) = 1·(−1)·2 + 2·2·5 + 4·0·4
       − 5·(−1)·4 − 4·2·1 − 2·0·2
       = −2 + 20 + 0 + 20 − 8 − 0
       = 30

det(E) = 3 · 30 = 90

RU. Преподаватель проверил ответ матричным калькулятором: 90. Важное замечание: внешний множитель 3 нельзя просто умножить на каждый элемент подматрицы — здесь умножается значение её определителя.

PL. Prowadzący sprawdził wynik kalkulatorem macierzy: 90. Ważne: współczynnik 3 mnoży wartość wyznacznika, a nie każdy element macierzy osobno.

5. Как решать на контрольной / Jak rozwiązywać na kolokwium

RU: 1) Убедись, что матрица квадратная. 2) Найди строку или столбец с наибольшим количеством нулей. 3) Для каждого ненулевого элемента вычеркни его строку и столбец. 4) Определи знак (−1)i+j. 5) Вычисли миноры. 6) Сложи произведения. 7) Проверь результат другим способом.

PL: 1) Sprawdź, czy macierz jest kwadratowa. 2) Wybierz wiersz lub kolumnę z największą liczbą zer. 3) Dla niezerowych elementów skreśl odpowiedni wiersz i kolumnę. 4) Ustal znak (−1)i+j. 5) Oblicz minory. 6) Zsumuj iloczyny. 7) Sprawdź wynik inną metodą.

Запомни / Zapamiętaj: разложение Лапласа работает для квадратных матриц любого порядка; выбор строки с нулями экономит вычисления. На следующем занятии преподаватель обещал завершить тему определителей и показать ещё один метод.

6. Самопроверка / Samokontrola

Почему выгодно выбирать строку с нулями? / Dlaczego wybieramy wiersz z zerami?

Потому что нулевые элементы дают нулевые слагаемые, и соответствующие миноры вычислять не нужно. / Ponieważ składniki z zerami znikają.

Какой знак у D₂₁? / Jaki znak ma D₂₁?

Отрицательный: (−1)^(2+1) = −1. / Ujemny.

Чему равен det(C)? / Ile wynosi det(C)?

17.

Чему равен det(E)? / Ile wynosi det(E)?

90.
