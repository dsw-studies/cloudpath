Python · с нуля

Python с нуля: минимум для первых заданий.

Самое базовое: ввод-вывод, переменные, условия, циклы, списки, функции. Примеры можно копировать и запускать. Если задание — «напиши программу», почти всегда нужны именно эти темы.

Запускать можно на компьютере (python.org, IDLE) или онлайн (например, в браузерных интерпретаторах). Лучший способ выучить — набрать каждый пример руками и менять числа.
1

Как запускать код

Python-программа — обычный текстовый файл с расширением .py. Строки выполняются сверху вниз. Запуск: в терминале python файл.py или кнопка Run в редакторе (IDLE, VS Code, PyCharm). Строка с # — комментарий, Python её игнорирует.

Первая программа: print выводит текст на экран.

print("Hello")
print("Сумма:", 2 + 3)   # Сумма: 5
# это комментарий
2

Переменные и типы

Переменная — имя для значения. Создаётся присваиванием =, тип определяется сам.

a = 5            # int — целое
b = 2.5          # float — дробное (точка, не запятая!)
name = "Anna"    # str — строка
ok = True        # bool — True / False
print(type(a))   # <class 'int'>

Арифметика. Важно: / всегда даёт дробь, // — целую часть, % — остаток, ** — степень.

print(7 / 2)    # 3.5
print(7 // 2)   # 3
print(7 % 2)    # 1   (остаток)
print(2 ** 10)  # 1024
x = 10
x += 3          # x = x + 3 -> 13

Преобразование типов и ввод. input() всегда возвращает строку — число надо превратить.

n = int(input("n = "))   # ввод целого
x = float("3.14")
print(str(5) + "a")      # "5a"
Потренируйся:
  1. Запиши в переменные длину и ширину прямоугольника и выведи площадь.
  2. Прочитай число n и выведи n в квадрате и остаток от деления n на 3.
3

Условия if

Выбор действия. Блок кода выделяется отступом (4 пробела) и двоеточием в конце строки условия — это главное правило Python.

x = int(input())
if x > 0:
    print("positive")
elif x == 0:
    print("zero")
else:
    print("negative")

Сравнения: == != < > <= >=. Логика: and or not. Одно = — присваивание, два == — сравнение!

if x % 2 == 0 and x > 10:
    print("чётное и больше 10")
Потренируйся:
  1. Определи, чётное ли число.
  2. По трём сторонам определи, существует ли треугольник (каждая сторона меньше суммы двух других).
4

Циклы for и while

for — когда известно сколько раз или по чему перебирать. while — пока условие истинно.

range(n) даёт 0, 1, …, n−1; range(a, b) — от a до b−1; range(a, b, шаг).

for i in range(5):
    print(i)           # 0 1 2 3 4

total = 0
for i in range(1, 101):
    total += i
print(total)           # 5050
n = 10
while n > 0:
    print(n)
    n -= 2             # 10 8 6 4 2
# break — выйти из цикла, continue — к следующему шагу
Потренируйся:
  1. Выведи сумму всех чётных чисел от 1 до 100.
  2. Прочитай число n и выведи его цифры по одной (подсказка: n % 10 и n // 10 в while).
5

Списки

Список — упорядоченный набор значений в квадратных скобках. Индексы начинаются с 0, отрицательные считают с конца.

a = [5, 2, 9]
print(a[0], a[-1])     # 5 9
a.append(7)            # [5, 2, 9, 7]
a.remove(2)            # убрать значение
print(len(a), sum(a), max(a))
a.sort()               # по возрастанию
print(a[1:3])          # срез: элементы 1 и 2

Перебор и «списковое выражение»:

for x in a:
    print(x)
sq = [x * x for x in range(5)]       # [0, 1, 4, 9, 16]
ev = [x for x in range(10) if x % 2 == 0]

Ввод списка чисел из одной строки «1 2 3»:

nums = list(map(int, input().split()))
Потренируйся:
  1. Найди среднее арифметическое списка.
  2. Выведи элементы списка в обратном порядке (a[::-1]).
6

Функции

Функция — именованный кусок кода, который можно вызывать много раз. return возвращает результат.

def square(x):
    return x * x

def max2(a, b):
    if a > b:
        return a
    return b

print(square(4))       # 16
print(max2(3, 8))      # 8

Переменные внутри функции живут только внутри неё. Рекурсия — функция вызывает саму себя (нужно условие остановки):

def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)
print(fact(5))         # 120
Потренируйся:
  1. Напиши функцию is_prime(n).
  2. Напиши функцию, возвращающую сумму цифр числа.
7

Строки, словари, множества

Строки похожи на списки (индексы, срезы), но неизменяемы.

s = "hello"
print(len(s), s[0], s.upper(), s[1:3])   # 5 h HELLO el
print("ell" in s)                         # True
words = "a b c".split()                   # ['a','b','c']
print("-".join(words))                    # a-b-c
print(f"x = {5 + 1}")                     # f-строка: x = 6

Словарь хранит пары ключ → значение, множество — уникальные элементы.

d = {"Anna": 5, "Jan": 4}
d["Ola"] = 3
for k, v in d.items():
    print(k, v)
st = {1, 2, 2, 3}            # {1, 2, 3}
8

Типичные ошибки

Что чаще всего ломает код новичка:

# 1. Забыли двоеточие или отступ  -> SyntaxError / IndentationError
# 2. = вместо ==  в условии
# 3. input() вернул строку: "5" + "3" = "53", а не 8 -> int(...)
# 4. Индекс за пределами списка -> IndexError (последний индекс len(a)-1)
# 5. Деление на 0 -> ZeroDivisionError
# 6. Имя написано иначе -> NameError (Python различает большие и маленькие буквы)

Читай сообщение об ошибке с конца: там тип ошибки, выше — номер строки.
