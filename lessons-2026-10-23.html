Programowanie w języku Python

Коллекции, строки, модули и случайные числа

Cel: zrozumieć różnice między listą, krotką, słownikiem i zbiorem oraz umieć korzystać z modułów standardowych.

По-русски: ты учишься хранить данные разными способами и выбирать подходящую структуру под задачу.

1. Lista — список

Lista jest uporządkowana, modyfikowalna i dopuszcza powtarzające się elementy.

Список хранит элементы по индексам, начиная с нуля. Его можно менять.
a = [10, 20, 20, 40]
print(a[0])        # 10
print(a[::-1])     # [40, 20, 20, 10]
a.reverse()        # меняет сам список
a.sort()           # сортирует по возрастанию
print(len(a))      # 4

Важное уточнение: a.reverse() меняет список и возвращает None; reversed(a) возвращает итератор, а a[::-1] — новый список. Это объясняет ошибки при цепочках вызовов, обсуждавшиеся на занятии.

2. Krotka — кортеж

Krotka jest uporządkowana, ale nie pozwala na zmianę swoich elementów.

Похожа на список, но нельзя присвоить новое значение элементу по индексу.
t = (10, 20, 30)
print(t[1])  # 20
print(sum(t)) # 60
# t[1] = 5  # TypeError

Кортеж также можно записать как 10, 20, 30.

3. Słownik — словарь

Słownik przechowuje pary klucz–wartość.

Обращаемся по ключу, а не по номеру. Удобно для JSON и API.
d = {"name": "Anna", "age": 20}
print(d["name"])
for k, v in d.items():
    print(k, v)
print(list(d.keys()))
print(list(d.values()))

4. Zagnieżdżone słowniki — вложенные словари

Можно хранить словарь внутри словаря, а также списки внутри словаря.

student = {"name": "Anna", "profile": {"city": "Wrocław"}}
print(student["profile"]["city"])  # Wrocław

JSON: json.dumps(d) превращает объект в JSON-текст; json.loads(tekst) читает JSON. Python dict и JSON не идентичны по типам и правилам.

5. Zbiór (set) — множество

Zbiór przechowuje unikalne elementy; nie gwarantuje kolejności.

Если из списка нужно убрать повторения, можно превратить его в множество, но порядок может измениться.
numbers = [1, 2, 2, 3, 1]
unique = list(set(numbers))
ordered_unique = list(dict.fromkeys(numbers))
A, B = {1, 2, 3}, {3, 4}
print(A | B)  # объединение
print(A & B)  # пересечение
print(A - B)  # разность

Важно: set не поддерживает reverse() и срезы. Для обратного порядка сначала нужна упорядоченная последовательность.

6. Import i czas — модули и время

Import pozwala korzystać z funkcji i klas innych modułów.

import calendar
print(calendar.month(2026, 10))
from datetime import datetime
print(datetime.now())
import time
start = time.perf_counter()
sum(range(100000))
print(time.perf_counter() - start)
Можно импортировать весь модуль (import math), отдельную функцию (from math import sqrt) или использовать псевдоним (import math as m).

Упоминавшийся time.clock() удалён из современного Python: используй time.perf_counter().

7. Napisy (str) — строки

Napis jest niemodyfikowalnym ciągiem znaków.

s = "Ala ma kota"
print(s[0])        # A
print(s[::-1])     # atok am alA
print("kot" in s)  # True
print(s.upper())
print(s.lower())
print(s.capitalize())
for znak in s:
    print(znak)
Строка похожа на последовательность: её можно индексировать и перебирать, но менять отдельные символы напрямую нельзя.

8. Cudzysłowy, UTF-8 i formatowanie

Cudzysłowy: można użyć pojedynczych, podwójnych lub potrójnych cudzysłowów.

s = 'Powiedział: "Cześć"'
s2 = "Powiedział: \"Cześć\""

UTF-8: kodowanie obsługuje polskie znaki; LF i CRLF to sposoby kończenia linii.

tekst = "Zażółć gęślą jaźń"
b = tekst.encode("utf-8")

Русский перевод: UTF-8 отвечает за представление символов, а LF/CRLF — за перенос строки. В Python 3 исходный код по умолчанию читается как UTF-8, но консоль может иметь отдельные настройки.

imie, ocena = "Anna", 4.756
print(f"{imie}: {ocena:.2f}")  # Anna: 4.76
print("{}: {:.2f}".format(imie, ocena))

f-string позволяет вставлять переменные внутрь строки и задавать точность.

9. math — математика

import math
print(math.pi)
print(math.e)
print(math.sqrt(16))       # 4.0
print(math.factorial(5))   # 120
print(math.sin(math.pi/2)) # 1.0
print(2 ** 3)              # 8
print(math.pow(2, 3))      # 8.0
Тригонометрические функции принимают радианы; ** — встроенный оператор степени.

10. random — случайные значения

import random
print(random.randrange(2, 10))
print(random.choice(["A", "B", "C"]))
a = [1, 2, 3, 4]
random.shuffle(a)
print(a)
print(random.random())
Это псевдослучайные числа. seed() позволяет воспроизводить последовательность, но не превращает её в истинно случайную.

11. Sprawdź się — проверь себя

Почему list(set([2,2,1])) не гарантирует исходный порядок? Чем отличаются d.items() и d.values()? Почему lista.reverse().sort() вызывает ошибку?

Показать ответы

Set не сохраняет порядок; items даёт пары (ключ, значение), values — только значения; reverse возвращает None, у которого нет sort.

Analiza matematyczna · teoria mnogości

Iloczyn kartezjański i indeksowana rodzina zbiorów

Dwa fragmenty nagrania: dowód rozdzielności iloczynu kartezjańskiego względem sumy oraz definicja rodziny indeksowanej.

По-русски: разбираем упорядоченные пары, доказываем равенство множеств и учимся обозначать целые семейства множеств через индексы.

1. Iloczyn kartezjański — декартово произведение

Dla zbiorów X i Y: X × Y = {(x, y) : x ∈ X oraz y ∈ Y}.

X × Y = {(x, y) | x ∈ X ∧ y ∈ Y}

Дополнительный пример: X = {1, 2}, Y = {a, b}. Тогда X × Y = {(1,a), (1,b), (2,a), (2,b)}.

2. Twierdzenie o rozdzielności — распределительный закон

(X₁ ∪ X₂) × Y = (X₁ × Y) ∪ (X₂ × Y)

Dowód: dla dowolnej pary (x,y) rozpisujemy warunki przynależności i stosujemy prawo rozdzielności koniunkcji względem alternatywy.

(P ∨ Q) ∧ R ⇔ (P ∧ R) ∨ (Q ∧ R)

Dowód krok po kroku / доказательство:

(x,y) ∈ (X₁ ∪ X₂) × Y

⇔ x ∈ (X₁ ∪ X₂) и y ∈ Y — определение декартова произведения.

⇔ (x ∈ X₁ ∨ x ∈ X₂) ∧ y ∈ Y

⇔ (x ∈ X₁ ∧ y ∈ Y) ∨ (x ∈ X₂ ∧ y ∈ Y) — распределительный закон.

⇔ (x,y) ∈ X₁ × Y ∨ (x,y) ∈ X₂ × Y
⇔ (x,y) ∈ (X₁ × Y) ∪ (X₂ × Y)

C.N.D. — co należało dowieść.

Мы взяли произвольную пару и показали, что она принадлежит левой стороне тогда и только тогда, когда принадлежит правой. Значит, множества равны.

3. Nieprzemienność — некоммутативность

X × Y ≠ Y × X (na ogół / обычно)
X × Y

(1,a), (1,b), (2,a), (2,b)

Y × X

(a,1), (a,2), (b,1), (b,2)

Порядок внутри пары важен: (1,a) и (a,1) — разные упорядоченные пары. При X = Y произведения совпадают; в общем случае — нет.

4. Zbiór wskaźników — множество индексов

Niech T będzie zbiorem wskaźników, a Y dowolnym zbiorem. Zbiór potęgowy P(Y) to zbiór wszystkich podzbiorów Y.

𝒫(Y) = {A | A ⊆ Y}

Дополнительный пример: Y = {a,b}, тогда 𝒫(Y) = {∅, {a}, {b}, {a,b}}.

Funkcja F : T → 𝒫(Y) przyporządkowuje każdemu t ∈ T podzbiór F(t) = Fₜ zbioru Y.

F : T → 𝒫(Y)   ·   F(t) = Fₜ

Rodzinę (Fₜ)ₜ∈T nazywamy indeksowaną rodziną zbiorów.

T — номера, Y — общее множество, 𝒫(Y) — все его подмножества, F — правило, а Fₜ — множество с номером t. Разные индексы могут обозначать одинаковые множества.

5. Ćwiczenie — самостоятельная проверка

Пусть X₁={1}, X₂={2}, Y={a,b}. Выпиши обе стороны (X₁∪X₂)×Y и сравни.

Показать решение

Левая сторона: {(1,a),(1,b),(2,a),(2,b)}. Правая: {(1,a),(1,b)} ∪ {(2,a),(2,b)}. Результат совпадает.
